 # 🩺 Explainable Skin Cancer Classification using EfficientNetB0 and Grad-CAM

## 📌 Project Overview

This project presents an Explainable Deep Learning framework for multi-class skin cancer classification using the HAM10000 dermoscopic image dataset. The model is developed using EfficientNetB0 with transfer learning and Grad-CAM to provide visual explanations for predictions.

---

## 🎯 Objectives

- Classify dermoscopic skin lesion images into seven classes.
- Improve diagnostic assistance using transfer learning.
- Provide visual interpretability using Grad-CAM.
- Evaluate model performance using standard classification metrics.

---

## 🗂 Dataset

- **Dataset:** HAM10000
- **Total Images:** 10,015
- **Classes:** 7

Classes include:

- Actinic Keratoses (akiec)
- Basal Cell Carcinoma (bcc)
- Benign Keratosis (bkl)
- Dermatofibroma (df)
- Melanoma (mel)
- Melanocytic Nevus (nv)
- Vascular Lesions (vasc)

---

## 🧠 Model

- EfficientNetB0 (Transfer Learning)
- TensorFlow / Keras
- Fine-Tuning
- Grad-CAM (Explainable AI)
